\section{实验：构建个人主页}
\label{sec:experiment}

我们通过一次自我实验来评估两种策略：构建一个包含自我介绍、数据可视化和交互彩蛋的个人主页。
任务由一名无编程背景、设计经验有限的大学生完成。

\subsection{策略A：增量构建（Codex）}

首先使用OpenAI的Codex尝试了增量构建策略。
用户让AI构建页面骨架（HTML结构+基础CSS样式），然后添加了开屏动画和背景图。
计划是随后逐个模块添加内容。

\textbf{结果：}整个过程在骨架阶段即停滞。
AI生成的骨架模板感强烈，缺乏设计辨识度。
用户报告感到"缺乏掌控"——虽然每个元素都是通过用户的Prompt添加的，但用户对最终成品没有任何清晰的画面。
没有设计锚点，每次Prompt本质上都是在设计空间中的随机游走。

\textbf{失败分析：}我们识别出三个具体的失败模式：

\begin{enumerate}
    \item \textbf{缺乏设计锚点。}在未首先确定色彩方案、字体或设计哲学的情况下，每次Prompt都在真空中运作。AI生成的代码在技术上正确，但在美学上毫无方向。
    \item \textbf{可预见的沟通成本攀升。}虽然过程在添加大量模块之前就停止了，但用户已能预见：每个后续模块都需要越来越精准的Prompt来匹配模糊的想象画面——沟通成本将随模块数量线性增长。
    \item \textbf{风格漂移风险。}没有统一的设计文档，独立Prompt生成的每个模块最终会形成互不一致的视觉风格——颜色不匹配、间距不对齐、动画性格各异。
\end{enumerate}

\subsection{策略B：设计优先（Claude Code）}

随后使用Anthropic的Claude Code（Claude Opus 4.8模型）尝试了设计优先策略。
按照第\ref{sec:method}节描述的五步方法论，用户将大约20\%的对话轮次用于编码前的设计构思。

\textbf{结果：}最终实现包含约3,700行代码（HTML: 470行，CSS: 约3,100行，JavaScript: 约1,700行），并包括以下内容：

\begin{itemize}
    \item \textbf{六个按序排列的区域}，带有平滑滚动导航和章节分隔符。
    \item \textbf{四个主题数据可视化面板}，分别对应游戏（像素卡带+精灵动画）、音乐（旋转黑胶唱片+声波柱）、影视（复古电影票根）和动漫（CRT电视+扫描线+弹幕）。
    \item \textbf{横向翻阅"招牌交互"}，基于GSAP ScrollTrigger的pin+scrub实现，将垂直滚动输入映射为卡片水平遍历，并带有聚光灯聚焦效果。
    \item \textbf{分层彩蛋系统}：时间感知问候（自动显示）、隐藏歌单（点击触发）、隐藏一句话（悬停超时触发）、贪吃蛇小游戏（连续点击页脚装饰符5次触发）、彩蛋成就徽章收集。
    \item \textbf{手帐风格视觉装饰}：和纸胶带、印章、碎纸片、手绘线条、日期贴纸和页码——全部使用CSS实现，无需额外图片资源。
    \item \textbf{响应式设计}，移动端降级策略（640px以下横向翻阅替换为竖直卡排列）。
\end{itemize}

\subsection{体验驱动的迭代}

一个重要发现是：即使有完整的设计文档，第一版实现（v1.0）仍存在只有在实际浏览器测试中才会发现的问题。
这些问题包括：回到顶部按钮与页脚背景融合导致几乎不可见（视觉权重不足）、导航链接点击后直接跳转而非平滑滚动（功能正确但审美上突兀）、社交图标存在行为错误或缺失（mailto:链接在未配置邮件客户端的电脑上无效、音乐图标使用了时钟图案的SVG），以及卡片表面光泽渲染时过亮。

每个问题都通过针对性的纠正Prompt解决，且纠正均以设计文档中的美学约束为参照。
这种体验驱动的迭代循环是设计优先策略的自然补充：文档提供了目标，浏览器揭示了目标与现实之间的偏差，用户提供精准的纠正。

\subsection{实现统计}

最终代码库包含三个文件共约3,700行：\texttt{index.html}（页面结构，六语义区域，470行）、\texttt{style.css}（全部样式，CSS自定义属性，900px和640px两处响应式断点，约3,100行）、\texttt{script.js}（GSAP驱动的交互，包含横向翻阅、粒子生态系统、数据面板主题切换、彩蛋触发、贪吃蛇游戏引擎、时间氛围切换，约1,700行）。
网站通过GitHub Pages部署于\url{https://qaq82625.github.io/-v2.0/}。
完整对话约200+轮，涵盖设计构思、代码实现和迭代优化三个阶段。
