\begin{abstract}
This experiment used AI coding tools to build a personal homepage featuring self-introduction, data visualization, and interactive easter eggs, deployed on GitHub Pages.
The experiment proceeded in two phases: Phase~1 used Codex with an \textit{Incremental Build} strategy (construct a page skeleton, then add modules one by one), which stalled at the skeleton and splash screen stage due to the lack of a core design concept and a sense of design control.
Phase~2 switched to Claude Code with a \textit{Design-First} strategy---before writing any code, approximately 20\% of dialogue rounds were spent co-designing a complete specification (design philosophy, color system, typography, six-region architecture, animation specifications) with the AI, compiled into a roughly 700-line design document, followed by specification-driven implementation.
The resulting homepage, with the ethos of ``Warmth~$\times$~Sharpness~$\times$~Vitality,'' includes four independently themed data visualization panels, a signature horizontal-scroll interaction powered by GSAP ScrollTrigger, a five-tiered footer easter egg system, and a hidden Snake mini-game.
The comparison of the two strategies demonstrates that, for non-technical users, explicitly separating design ideation from code implementation effectively compensates for the user's own design limitations and enables full utilization of the AI's design capabilities.
\end{abstract}
